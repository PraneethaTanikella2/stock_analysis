\# Infosys SmartStock – Inventory Optimization for Retail Stores



A machine learning project for forecasting retail store inventory using:

\- Python

\- Pandas, NumPy

\- Matplotlib \& Plotly

\- Scikit-learn

\- Streamlit interactive dashboard



\## How to Run



\### 1. Create virtual environment

python -m venv venv

venv\\Scripts\\activate



\### 2. Install dependencies

pip install -r requirements.txt



\### 3. Run the Streamlit App

streamlit run app.py



\## Project Structure

\- data/ → cleaned dataset

\- models/ → trained ML models

\- outputs/ → graphs (plots)

\- app.py → Streamlit Dashboard

\- eda\_analysis.py → Exploratory Data Analysis

\- model\_training.py → ML model training
